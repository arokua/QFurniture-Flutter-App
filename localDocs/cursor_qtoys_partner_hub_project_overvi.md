Here’s what was going wrong and what we changed.

### Root causes
1. **Wrong cart when closing WebView** – The in-page `fetch('/wp-json/wc/store/v1/cart')` was sending the app’s **`Cart-Token`** header. That can refer to a **different** session than the browser’s cookies, so the JSON often didn’t match what you saw on the site.
2. **Overwrite after a good pull** – `_syncAfterWebView` always called **`refreshFromRemote()`** right after applying the WebView cart. That used the **old** app session and could **replace** the cart you’d just pulled from the web.
3. **Merge rules blocked sync** – `applyStoreCartFromJson` refused to apply an **empty** server cart when the app still had lines, and `refreshFromRemote` wouldn’t replace a non-empty local cart with an empty remote, so “cleared on web” never showed in the app.
4. **Session not aligned after web** – The Store API **`token`** in the cart JSON wasn’t persisted, so the app client could stay on the wrong session.
5. **JWT WebView vs app cart** – With **`attemptWebLogin`**, the WebView **didn’t** get the app’s cookies first, so the browser often started in another session than the Store API client.

### Fixes
- **`StoreCartApiService`**: `absorbCartSessionFromCartJson()` reads **`token`** (and common `extensions.woocommerce` shapes) from `GET /cart` JSON and saves **`Cart-Token`** so the app matches the browser session.
- **`StoreWebViewScreen`**:  
  - WebView cart fetch uses **only** `credentials: 'include'` (**no** `Cart-Token` header).  
  - After a successful pull: absorb token (unless wholesale), apply JSON to `cartProvider`.  
  - **`refreshFromRemote`** runs **only if** the pull failed.  
  - **`ref.invalidate(storeCartTotalsProvider)`** after sync.  
  - For **`attemptWebLogin`** (and not wholesale): **`_injectStoreCartCookies()`** before loading so the WebView shares the app’s session.
- **`CartNotifier`**: Initial load / `refreshFromRemote` always mirror the server when the request succeeds (including **empty** cart), and absorb session from the response body when present.
